# Contributing

Submit a new example or improve an existing prompt with a pull request.

1. Include the complete prompt and a matching preview you may share.
2. Describe the subject, medium, palette, lighting, and composition clearly.
3. Use a new stable numeric ID and a descriptive lowercase slug. Do not reuse IDs.
4. Add a record to `prompts.json`, the preview and thumbnail, and the exact prompt TXT.
5. Add the matching HeyDreaming page through the website catalog sync before publishing its link.
6. Run `npm run build` and `npm run verify`.

Keep private account IDs, credentials, source-image URLs, job records, and billing data out of this repository. Do not present model-specific results without a matching verified generation.

For a correction, include the public prompt ID and a short explanation. Do not replace another example's ID or slug.
